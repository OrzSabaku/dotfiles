# 通知の自動消去

Omarchy標準の通知プラグインのユーザー側コピーです。
変更は重要通知の表示時間を無期限から15秒にする部分だけです。
通常通知は8〜30秒、低優先通知は5〜30秒という標準動作を維持します。
右クリックで閉じる機能も標準のままです。ホバー中はカウントが止まり、内容更新時は再開します。
履歴には標準どおり残ります。

有効化: `~/dotfiles/scripts/enable-notification-timeout`
復元: `omarchy plugin enable omarchy.notifications`

標準側の更新は自動では取り込まれません。upstream.jsonは複製元のハッシュです。
更新時は標準との差分を確認し、15秒の変更を維持して同期してください。
