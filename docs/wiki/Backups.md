# 移行時のバックアップ

過去の移行で使った戻り先のメモです。保存場所は当時の記録で、現在の存在は再確認していません。
バックアップは `~/.local/state/dotfiles/backups/` 以下にあります。

| 移行 | バックアップ名 |
|---|---|
| ファイル単位リンクへの配置変更 | `20261018-024831-cc8aa2f5/` |
| Neovim共通化 | `20261018-030634-842018b1/` |
| 廃止したNeovimのテーマ・実験リンク | `neovim-retired-20261018-030633/` |
| シェル・Ghostty共通化 | `20261018-030904-9d12b6e5/` |
| モニター配置 | `monitors-20261018-202501/monitors.lua` |
| Gitの個人設定分離 | `git-global-20261020-021309/` |
| Marketplace版プラグインへの移行 | `marketplace-plugins-20261021-140256/` |
| プラグイン開発用ソースの撤去 | `plugin-development-removal-20261021-140835/` |

Neovim共通化後は読み込み処理も変えたため、当時のバックアップの一括復元が変更検出で止まる場合があります。
現在の変更を保存し、Git差分を確認して対象を選びます。

プラグイン開発用ソースの撤去時には、Git履歴のbundleと旧リンクの実体コピーを残しました。
撤去済みソースを指す古いリンクを戻さず、実体コピーを使います。
開発を再開する場合は、公開リポジトリかbundleからdotfilesの外へcloneします。
